# STM32 LED Blink Bare Metal

Simple LED blinking project using STM32F401RE and register-level programming.

## Microcontroller
STM32F401RE

## IDE
STM32CubeIDE

## Language
C

## Features
- GPIO output configuration
- LED blinking
- RCC clock enabling
- Register-level programming

## Registers Used
- RCC_AHB1ENR
- GPIOA_MODER
- GPIOA_ODR

## Concepts Learned
- GPIO configuration
- Bitwise operations
- Bare-metal programming
